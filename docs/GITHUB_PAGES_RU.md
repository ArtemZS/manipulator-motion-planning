# Публикация showcase через GitHub Pages

Публичная галерея: https://artemzs.github.io/manipulator-motion-planning/showcase/index.html

GitHub Pages публикует корень ветки `gh-pages`. Эта ветка содержит только
статический сайт: шесть сцен, анимации, изображения, таблицы и общую статистику.
Код проекта и исходные результаты экспериментов развиваются отдельно.
Презентации и текст выступления в сайт не входят.

Подготовка обновлённой копии из сохранённых результатов:

```powershell
just pages-export .cache/pages-site-new
```

Выходной каталог должен быть пустым. Экспорт читает `results/showcase/` и
`docs/experiments/`, выносит GIF и общий код Plotly в отдельные ресурсы,
проверяет относительные ссылки. Данные движений и численные результаты
не пересчитываются. Сначала обновите локальную галерею и отчёт, затем экспортируйте сайт.

Для обновления публикации перенесите готовый экспорт в checkout ветки `gh-pages`,
сохранив её историю Git, создайте коммит и отправьте ветку в `origin`.
GitHub Pages автоматически опубликует изменения. Обычный push ветки с кодом
не заменяет опубликованную копию галереи.

Локальная галерея после `just serve`: http://127.0.0.1:8766/showcase/index.html
