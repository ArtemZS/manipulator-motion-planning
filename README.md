# Оптимизация траекторий пространственного манипулятора 6R

Исследовательский проект для ВКР: RRT* ищет путь в пространстве шести углов,
зажатый B-сплайн пятой степени задаёт движение суставов, NSGA-II одновременно
изменяет коэффициенты сплайна и длительность движения. Пример содержит сферу
и параллелепипед: прямая интерполяция между стартом и целью пересекает препятствие.

Проект использует **Python 3.14**, **uv**, **just** и локальный **Git**.
Адрес удалённого репозитория пока не задан; проект предназначен для личного GitHub.

## Запуск

Из корня проекта:

```powershell
just sync
just quick
just demo
just replay results/demo
```

`quick` выполняет весь каскад с уменьшенным бюджетом: 180 итераций RRT*,
12 особей и 5 поколений. Обычная демонстрация использует 500 итераций,
32 особи и 24 поколения. Seed по умолчанию — 42. Время зависит от компьютера;
конечный случайный поиск может завершиться без пути, что отражается в статусе и коде выхода.

Те же команды без just:

```powershell
uv sync --locked
uv run manipulator-planning demo --output results/demo
uv run manipulator-planning demo --quick --no-plots --output results/numeric
uv run manipulator-planning replay results/demo --no-plots
uv run manipulator-planning demo --scene configs/simple.yaml --seed 42
```

В `justfile` кэши uv и Matplotlib направлены в `.cache` внутри проекта.
Версии зависимостей закреплены в `uv.lock`; установка не требует PyBullet,
компилятора C++ или отдельного графического симулятора.

## Модель

Источник геометрии, масс и инерций —
`src/manipulator_planning/assets/educational_6r.xml` в формате MJCF.
Модель стационарная, шесть вращательных суставов имеют локальные оси
`z, y, y, x, y, x`. Геометрия звеньев — капсулы; инерции вычисляются MuJoCo
из их геометрии и масс. Основание неподвижно; гравитация `[0, 0, -9.81] м/с²`.

| Звено | Длина осевого отрезка, м | Радиус, м | Масса, кг |
| --- | --- | --- | --- |
| 1, вертикальная стойка | 0.10 | 0.055 | 1.00 |
| 2, плечо | 0.42 | 0.042 | 0.90 |
| 3, предплечье | 0.34 | 0.036 | 0.70 |
| 4, запястье | 0.16 | 0.031 | 0.30 |
| 5, запястье | 0.14 | 0.027 | 0.20 |
| 6, инструмент | 0.12 | 0.024 | 0.12 |

Ограничения скоростей, ускорений и моментов заданы в `robot.py`.
Это учебные параметры, а не паспортные данные реального робота.
Все линейные величины — в метрах, углы — в радианах, время — в секундах.
Объёмная сцена имеет размерность 3, пространство конфигураций — размерность 6.

Для Python 3.14 выбран MuJoCo: при проверке окружения готовой совместимой
сборки PyBullet не оказалось. MuJoCo обеспечивает единую геометрию,
прямую кинематику, матрицу инерции и обратную динамику RNE.
Модель поставляется в MJCF, импорт/экспорт URDF в этой версии не реализован.

## Постановка оптимизации

При нормированном параметре `u=t/T`:

```text
q(t) = Σ B_i,5(t/T) P_i
q_dot = q_u' / T; q_ddot = q_u'' / T²; q_dddot = q_u''' / T³

min [J_tau, J_jerk, T]
J_tau  = integral(tauᵀ tau dt),       [(Н·м)²·с]
J_jerk = integral(||q_dddot||² dt),   [рад²/с⁵]
tau = M(q) q_ddot + C(q,q_dot) q_dot + G(q)
```

`J_tau` — затраты управляющих усилий, **не электрическая энергия в джоулях**.
Фрикционные потери и модель электроприводов не добавляются.

Первые три коэффициента равны старту, последние три — цели: движение
начинается и заканчивается с нулевыми скоростями и ускорениями.
Обычная модель с 12 коэффициентами имеет 37 свободных переменных:
36 компонент коэффициентов и T. При неудаче аппроксимации пайплайн
может увеличить число коэффициентов.

RRT* использует нормированные диапазонами суставов расстояния, проверенные
рёбра, точную целевую конфигурацию и распространение стоимости при rewiring.
После первого найденного пути поиск продолжается до бюджета.
Диагностический обход в YAML используется тестами, планировщику он не передаётся.

NSGA-II реализован через pymoo: SBX, полиномиальная мутация, недоминируемый
отбор и crowding distance. Критерии и нарушения ограничений разделены.
Форма изменяется в явно ограниченной окрестности исходных коэффициентов
радиусом 0.12 рад; это ограничение поиска, а не штраф в критерии усилий.
Допустимые кандидаты сохраняются вне последней популяции, поэтому итоговых
решений может быть больше, чем особей. Финальная проверка рассматривает
до 48 кандидатов из нескольких фронтов и отдельно сохраняет исходный сплайн.
Компромисс выбирается по минимальному нормированному расстоянию до идеала
с одинаковыми весами трёх критериев.

## Проверка допустимости и границы выводов

Проверяются все звенья против препятствий, пола и основания, а также
несоседние пары звеньев. Исключены только соседние соединения и крепление
первого звена к основанию. Безопасный зазор примера — 0.015 м.

Для рёбер RRT* и сплайнов применяется адаптивное деление интервалов:
расстояние в середине сравнивается с консервативной оценкой смещения всей
геометрии. Неразрешённый интервал отклоняется. Эта оценка относится к
заданной модели примитивов и численным расстояниям MuJoCo.
Пределы углов, скоростей и ускорений проверяются оболочками коэффициентов.
Моменты проверяются на 301 отсчёте; непрерывная гарантия для моментов не заявляется.
Интегралы считаются квадратурой Гаусса отдельно на сплайновых участках.

Возвращается приближённый фронт найденных и проверенных решений;
сертификата глобальной Парето-оптимальности нет. GIF показывает кинематическое
воспроизведение. Следование траектории регулятором в прямой динамике в этой
версии не реализовано. Цель задаётся суставными углами; интерфейс задания
полной пространственной позы и обратная кинематика остаются следующим этапом.

## Проверки и структура кода

```powershell
just test
just check
just build
```

Тесты проверяют кинематику, гравитацию через градиент потенциальной энергии,
положительность матрицы инерции, столкновения, обновление стоимости дерева,
границы и производные сплайна, закон масштабирования рывка, недоминирование,
сохранение и повторное вычисление критериев. Сквозной тест использует реальную
3D-сцену, в которой прямая траектория заблокирована.

| Модуль | Назначение |
| --- | --- |
| `robot.py`, `collision.py` | Модель MuJoCo, динамика, геометрия и проверка движения |
| `planning.py` | RRT* и упрощение проверенного пути |
| `trajectory.py` | Аппроксимация и аналитические производные B-сплайнов |
| `objectives.py`, `validation.py` | Физические критерии и ограничения |
| `optimization.py` | Задача pymoo, NSGA-II и архив кандидатов |
| `pipeline.py`, `cli.py` | Полный запуск, сохранение и повторная проверка |
| `visualization.py` | PNG, GIF и автономный HTML |

Комментарии и докстринги написаны на русском. Исходный подробный план
находится в `docs/IMPLEMENTATION_PLAN_RU.md`; он сохраняет первоначальные
проектные предложения, включая заменённый впоследствии движок PyBullet.
